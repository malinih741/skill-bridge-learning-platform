# SkillBridge – Skill Development & Certification Platform

Learning platform: enrol in courses, complete lessons, take quizzes, submit projects, earn verifiable certificates.

## Status
- [x] Day 1 – React (Vite) frontend: home, course catalogue, course details, login/register UI (static data)
- [ ] Week 2 – Django REST API
- [ ] Week 3 – MySQL + authentication
- [ ] Week 4+ – Integration, quizzes, projects, certificates, deployment

## Run the frontend
```bash
cd frontend
npm install
npm run dev
```
Open http://localhost:5173

## Tech stack
React + Vite, React Router · (planned) Django REST Framework, MySQL

## Known limitations
Course data is static for now; login/register forms are UI only.
